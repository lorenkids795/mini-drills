## Key architecture — reusable curated mission generation, not improvisation at runtime
1. Separate **content planning** (approved passage sense IDs and actual learner states), **authored/editorially validated content packs**, **mission task construction** and **delivery/persistence**. The browser must NOT call a generative model to compose unchecked questions. AI may draft candidates OFFLINE for teacher review; only a versioned published pack can enter learner gameplay.
2. Study 102 approved P1 senses and group into coherent 4–7-word thematic missions. A single theme must have meaningful narrative coherence and cover as much approved bank as realistically possible. Do not promise one narrative covers every word if some senses need other types of practice. Provide a complete coverage matrix (covered, covered as context, deferred with reason, ambiguous), with a realistic plan for eventual 102/102 learning routes. Keep passage source and sense ID mapping correct; never alter approved bank to fit a story.
3. Build the initial **curated pilot** with at least 3 diverse mission packs (not merely reskinned Town on the Move), using approved P1 terms, each with an original short mission briefing, Case File one cumulative paragraph revealed sentence-by-sentence, contextual Investigate, story-linked Decode Evidence, appropriate Word Morph only when meaningful attested forms exist, Final Report independent recall, Debrief. Distinguish forms from base word evidence.
4. Content QA for every candidate: grammatical naturalness, source sense precision, collocations, one defensible MCQ answer, plausible distractors, non-revealing hints, accepted free-recall variants (case, punctuation, articles, inflections only when semantically sound), honest and useful explanations, copyright-safe original authored contexts. Flag teacher-review items; do not silently approve AI-created content.
5. Personalization planner: input approved sense IDs plus immutable snapshot of actual Vocab Check statuses (new, unsure, self_reported_known, verified_for_current_task, needs_practice) and recent per-form evidence. Pick pack with eligible overlap, avoid duplicate senses and overtesting verified words. Select task paths: Discover for new, Strengthen for unsure/failed, light contextual check for unverified Know It, verified skip basic checks but available as integrated story context. Permit mission after a batch 12 or 20; no requirement to finish 102. If no eligible pack, show truthful 'No mission for these words yet' with Continue Sorting.
6. Fixed mission run snapshot contentVersion, planVersion, sourceLesson, selected sense IDs, eligibility evidence and taskIDs. Resume exactly the same prompts across reloads, including independent typed draft, and never silently revise already-started tasks. No fake Mastered; answers after hint/retry marked assisted; avoid false review claims.
